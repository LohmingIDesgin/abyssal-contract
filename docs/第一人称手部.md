# 第一人称手部（3D 三渲二）

## 画面分层
```
WaterView（2D）        天空、礁石、海、船头、浮漂、鱼线
  ↑ 叠加
SubViewport（3D，透明） FirstPersonArms：双手（平涂手绘着色）+ 鱼竿（手绘贴图条带）
  ↑ 叠加
HUD                    张力条、出航面板、提示文字
```
鱼线是 2D 画的，起点取 3D 竿尖（贴图顶端圆环中心）投影到屏幕的位置（`FirstPersonArms.rod_tip_screen_position()`）。

美术参考：`docs/reference/concept_first_person.webp`（构图）、`docs/reference/style_hands_flat.png`（手的画风）、`docs/reference/rod_source.webp`（鱼竿原画）。

## 模型：`钓鱼动画.glb`
- `右手_001` / `左手_002`：各 25 根骨骼。`Bone` 是肘部根骨，`Bone.001` 是前臂，之后是五指（拇指 `.002–.004`，食指 `.005–.009`，中指 `.010–.014`，无名指 `.015–.019`，小指 `.020–.024`）。**没有手腕骨**：五根掌骨（`.002/.005/.010/.015/.020`）的根部重合在手腕处，代码把它们一起转当作手腕。
- 两段自带动画只用来**采样手指姿势**：第 0 秒是 `pose_a`，最后一帧是 `pose_b`。
  - 右手：松握 → 攥紧，运行时按张力混合（握力）
  - 左手：手指微屈伸，收线时来回混合
- Blender 里的 SSP 线稿和 `ssp_white` 材质导不出来，Godot 里用 `shaders/toon.gdshader` 和 `shaders/toon_outline.gdshader` 重新做。

## 动作（`scripts/fp/first_person_arms.gd`）
大臂在画面外，用 **虚拟肩关节 → 肘关节铰链 → 虚拟手腕 → 竿梢惯性** 这条关节链驱动：

| 关节 | 自由度 | 说明 |
|---|---|---|
| 肩（`RIGHT_SHOULDER`） | 上抬 / 内外摆 / 内外旋 | 带动整条手臂。握竿时手臂外展，"前臂立起来"主要靠**肩外旋**（内旋为负） |
| 肘 | 屈伸 | 绕大臂和前臂所在平面的法线转 |
| 腕 | 竿往前压 / 往后翘 | 作用在五根掌骨上，鱼竿挂在中指掌骨上一起动 |
| 竿梢 | 细微颤动 | 木竿刚性高：惯性只带出很小很快的颤动，张力只压弯一点（`ROD_TENSION_BEND`），收线时按张力和挣扎微颤（`ROD_TREMBLE`） |

分层：
1. **基础站位** `_place_arms()`：按屏幕落点（`RIGHT_HAND_SCREEN` 等常量）摆放手臂，鱼竿穿过右拳的拳眼。
   - 拳眼：中指、无名指、小指各自弯成的圈（指根 / 中节 / 末节 / 指尖四点，`FINGER_LOOPS`）在垂直于竿的平面里拟合圆心；中指圈心 → 小指圈心的连线就是竿的轴线。食指不参与：原模型是扣扳机的形状，没有弯成圈
   - `GRIP_SKIN_INSET`：骨骼圈心不等于皮肤围出的空间，摆位时把竿轴沿视线往后推一点，让前面的指腹盖住竿
   - `ROD_GRIP_OFFSET`：额外微调（手部坐标：沿竿 / 往手指 / 往掌心），默认为 0
   - `ROD_BUTT_EXTRA`：握点到竿尾的长度，握把和竿尾露出拳头下方
   - `THUMB_CURL`：拇指额外弯曲，扣在竿上（原模型是握枪姿势，拇指伸直）
2. **姿势目标**：`BASE_POSES`（等待、收线等状态的基础姿势）+ `ACTIONS`（抛竿、提竿、钓上、断线、脱钩、假咬钩）。每个键是 `[时间, Vector4(肩上抬, 肩内摆, 肩内旋, 肘屈), 腕, 身体位移]`，用 **Catmull-Rom** 插值，经过关键帧时速度连续。
3. **弹簧跟随**：每个关节一个阻尼弹簧（`SHOULDER_SPRING` 等，频率越高跟得越紧，阻尼比越低回弹越多）；肘比肩晚 `ELBOW_LAG`、腕再晚 `WRIST_LAG` 读关键帧，形成"近端先动、远端跟随"。
4. **高频抖动**（张力、鱼挣扎）直接叠在弹簧输出上，不会被弹簧滤掉。

双手握竿：咬钩提竿后左手就伸过来，握住右手上方一段，收线时两手一起拉，钓上来一起抬；断线、脱钩时松手回到船舷边。
- 左手的握法和右手一样按指圈拟合：左手攥成拳（`LEFT_GRAB_CURL`，60° 时四指圈半径正好套住竿）后，四个指圈的圆心是拳眼中心，食指圈心 → 小指圈心是拳眼轴线。握竿时**拳眼轴线严格对齐竿、拳眼中心落在竿上**，竿一定从指圈里穿过
- 剩下绕竿转的角度用来让前臂尽量朝 `LEFT_GRAB_ELBOW`
- `LEFT_GRAB_WRIST`：握竿时左手腕往下弯。竿几乎是竖的，手腕不弯的话前臂只能横着摆，肘端（模型截断面）会露在画面中间
- `LEFT_GRAB_ABOVE`：左手握点在右手握点上方多远（一个拳头约 0.1），太小两只手会叠在一起
- 调 `LEFT_GRAB_ELBOW` / `LEFT_GRAB_WRIST` 时注意两件事：前臂太竖会从前面挡住右拳；太往左或太朝镜头，肘端的截断面会露进画面
- 收线状态下左手一直握着；各动作里的松紧曲线在 `LEFT_GRAB_CURVES`

抛竿：预备（竿梢往前一沉）→ 肩带大臂上抬、外旋把前臂立起来、肘再往回收、腕往后翘，到最高点 → 整条手臂打平甩出、腕最后抖出去 → 收势（肩回位、肘微微内收）。在 0.7 秒出手，和 `FishingView.CAST_FLIGHT` 对齐。

## 鱼竿（`scripts/fp/fishing_rod_3d.gd`）
- 贴图 `assets/textures/rod.png`（从原画裁切，保留原图透明通道）铺在**朝向镜头的半圆柱面**上（`CROSS_SEGMENTS` 段截面），沿 12 节骨节弯曲。贴图按投影宽度采样，正面看和原画一致；竿身有真实厚度，握着它的手指能正确挡在前面。
- `length` 竿长，`width_scale` 粗细倍率，`TIP_INSET` 顶端圆环中心的位置（鱼线挂点）。
- 换竿：替换 `rod.png`，竖直摆放、竿尖朝上、背景透明即可；宽高比会自动读取。

## 手部贴图（`tools/bake_arm_texture.py` → `assets/textures/arm_albedo.png`）
模型 UV 展得很干净（前臂一块、手掌一块、五指各一块，指尖有建模的指甲环），所以颜色和细节烘焙进贴图，不在着色器里实时算：
- 逐像素读取静止姿态下的 3D 位置、法线、骨骼权重
- 绷带：前臂一根轴、手掌一根轴（手腕是弯的）上的螺旋缠绕，`TURN_SHIFT` 条交错、越大越斜；后一圈压住前一圈，接缝有压痕阴影；撕裂毛边、线头、纤维、污渍、不规则破洞；缠到指根，收口是毛边
- 手指：裸露皮肤（斑驳色差）、关节褶皱、指甲（对准模型的指甲环）
- 两只手共用一张（UV 相同）
- 重新生成：`python tools/bake_arm_texture.py`（约 2 分钟，光栅化结果缓存在 `tools/.bake_cache_*.npz`）
- **生成的 PNG 可以直接在绘图软件里手绘修改**，改完不要再运行脚本覆盖

## 着色器参数
`toon.gdshader`（平涂手绘）：
- `albedo_texture`：上面的手部贴图
- `shade_tint`：暗面 = 贴图颜色 × 这个颜色（偏冷）
- `shade_threshold`：明暗分界（越大暗面越多），`shade_wobble`：交界线的手绘抖动
- `contour_width`：内轮廓线（表面越侧向镜头越容易描黑）
- `paper_strength`：纸张噪声
- `light_dir` / `light_tint`：月光方向和冷色（`FirstPersonArms.MOON_LIGHT_DIR` / `MOON_TINT`）
- `lamp_pos` / `lamp_color` / `lamp_energy` / `lamp_range`：船头鲸油灯，朝灯的一面多一档暖色。灯的位置由 `WaterView` 每帧给出屏幕坐标，`FirstPersonArms` 按 `LAMP_DEPTH` 换成手臂场景里的 3D 位置

`toon_outline.gdshader`：`outline_px` 描边像素宽度，`width_wobble` 线宽抖动。

## 和 Blender 配合
- **重新导出时保持骨骼名和对象名不变**，覆盖 `钓鱼动画.glb` 即可，代码按名字找 `右手_001`、`左手_002`、`Bone.xxx`。
- 想换手指姿势：改那两段动画的**首帧和尾帧**。右手首帧 = 最松的握法，尾帧 = 最紧的握法；左手同理。
- 想精修手的细节：直接在 `arm_albedo.png` 上画（UV 布局见上），或者在 Blender 里用它做底图继续画。
- 如果以后要逐帧精修某个动作，可以在 Blender 里做成完整动画导出，我在 Godot 里改成直接播放，替换掉 `ACTIONS` 表里对应的那一项。
