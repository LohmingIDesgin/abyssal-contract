# 渔获与船舱

改版阶段 A 的内容（见根目录《冥海契约_设计对照与实现计划》第 6 节）。数值全是占位值，等试玩日志测出产出再定。

## 流程
抛竿时按上钩表抽出种类，**同时生成这条个体**（`CatchGenerator.generate`），之后不再变：搏斗里的临时削弱不会改变最后钓上来的东西（交接文档 §4.3）。钓上来以后进入**渔获展示**，选一个去处才能接着钓：

| 去处 | 结果 |
|---|---|
| 留下 | 放进船舱，按时期占载荷；放不下时这个按钮是灰的 |
| 生吞 | 加饱腹；不出材料。2026-11-04 起生吞不再长级（玩家的等级去掉了），饱腹装不下的那部分就白吃了 |
| 处理 | 得到三类材料（血肉质、矿壳质、幽光质） |

放生 2026-11-04 删了（你说的）。船舱里的渔获随时可以在契约书里生吞、处理（腾地方）。按键：展示时 `1`–`3`；`Tab` 开关契约书（钓鱼中途不行），`Esc` 也能关，左上道具栏的船舱格子点一下也能开；契约书里点一条或按方向键选中，`1` `2` 生吞 / 处理。

自动垂钓（`Q`，2026-11-04；暂时禁用）钓上来的不经过展示：船舱放得下就直接留下，接着钓；放不下就停下来，照常展示，交给你选（《钓鱼与搏斗》"自动垂钓"）。

## 个体的各项用途（`scripts/core/catch_generator.gd`）
各项分开算，不合成一个总分（§4.3）：

| 项 | 怎么来 |
|---|---|
| 灵魂等级和时期 | **等级跟着时期走**（2026-11-03 你定的，`FishData.stage_levels`）：幼年期是这一种的最低等级，成年期是最高等级，成长期在中间。灰鲦三个时期都是 1 级；磷灯婆 1/2/3、溺者之手 2/3/4、千目窥渊鲶 2/3/4（原来 2–3 级）、渡魂白鲟 3/4/5；只差一级的血齿冥鲳（1–2）、盲眼噬骸鳗（2–3）成长期两级都有可能：灵魂强度过了门槛（这一种成长期的平均 + `growth_up_soul`，现在 0，一半一半）就是高的那一级，祭值也跟着高一截。<br>钓上来是哪个时期、几级，按那层水出几级的生物挑（`WaterLayers`，见下面"三层水"）；同一层水、同一级里，三个时期按 `stage_share`（45 / 35 / 20%）分 |
| 躯体规模 | 一个数值（`CatchData.body`，2026-11-04 你定的，代替原来的重量），按它分五档（`BalanceConfig.body_lines`，每一档含上限、不含下限）：<br>**小型** 0.1–0.5、**中型** 0.5–2.0、**大型** 2.0–5.0、**巨型** 5.0–15.0、**畸变** 15.0 以上。<br>每种生物成年期是一档（`FishData.adult_body`，这一种的上限），成长期小一档、幼年期再小一档，最小到小型；带「变异」的再大一档（`CatchGenerator.body_class_for`）。数值在那一档里按对数掷，中间的多、两头的少（三角形分布，`body_quantile`）；畸变掷到 45 为止。<br>现在各种的成年期（我定的，待你看）：灰鲦中型（成长期、幼年期都是小型）；血齿冥鲳、磷灯婆、溺者之手大型（中型、小型）；盲眼噬骸鳗、千目窥渊鲶、渡魂白鲟巨型（大型、中型）。<br>躯体规模管饱腹和分解的材料，**不进祭值** |
| 个头 | 躯体规模 ÷ 它那一档掷出来的平均数（`body_mean`），约 0.4–2.1：只看这一条在这一档里长得大不大，分解的材料跟着它的平方根走 |
| 灵魂强度 | 0–100：平均 `soul_base`（30）+ `soul_per_level`（10）×（等级 − 1）+ 时期偏移（`stage_soul_offset`：−8 / 0 / +10），上下浮动约 8（正态）；带「魂蕴」再 +20。展示时写它比同级同时期的平均"浓烈 / 寻常 / 稀薄" |
| 词条 | `affix_chance`（35%）的概率带一个普通词条；另外每条按各自的机会单独掷特殊词条：「变色」3%、「变异」1%（`data/affixes/`，`special`） |
| 能量 | 2026-11-04 由原来的"食后成长"改成的纯数值词条（你定的），只用来算祭值：`energy_by_level[等级]`（12 / 22 / 36 / 52 / 72）上下浮动 12%（正态，`energy_spread`，夹在平均的 0.6–1.5 倍之间）× 词条倍率（`energy_mult`，现在都是 1）。平均数照原来祭值的等级系数 × 10 定，所以各级的祭值和原来差不多 |
| 祭值 | 献给祂值多少（设计对照文档 8.4，`CatchGenerator.tribute_of`）：种类的 `tribute_base` × 时期系数（`stage_tribute`：1 / 1.2 / 1.4）× 能量 ÷ 10 ×（1.5 + 灵魂强度 × 0.05）（`tribute_soul_base`、`tribute_soul_weight`）× Π（1 + 词条的 `tribute_bonus`）。灵魂强度 40、能量 12 的灰鲦 1 级成长期是 1,512。黄昏供奉收的就是祭值（G2）。<br>2026-11-04 起算祭值的只有种族、时期、灵魂强度、能量（再加词条），躯体规模不算了（原来是"个头 × 1.5"，换成了固定的 1.5；等级系数并进了能量）。<br>2026-11-03 改（你说的数值膨胀）：原来是（等级² + 种族加成）× 时期系数 1 / 2 / 3.5，等级跟着时期走以后两样乘在一起，一种生物从幼年到成年差三四十倍，刚升 2 级钓上一条 3 级的就是需求的十倍。现在每高一级大约 ×1.6–2，成年比幼年再多四成，种族加成去掉了 |
| 饱腹 | 生吞时加多少饱腹（交接文档里叫食粮值；G2 以前是供奉的货币）：`hunger_per_body`（17）× 躯体规模^`hunger_body_power`（0.6）× 词条倍率（多肉 ×1.4、枯瘦 ×0.6）。0.3（小型）约 8，1（中型）17，3（大型）约 33，8（巨型）约 59，25（畸变）约 117。**只看躯体规模，不看等级**。<br>17 是换成躯体规模以后按整局模拟器重定的（原来按公斤是 12）：幼年的大多成了小型，12 的话三种走法偿清掉了 4–11 个点，17 和换以前差不多（《测量与预算》"躯体规模按种族和时期"） |
| 处理材料 | 种类的 `yield_base` × `yield_scale`（0.36；换成躯体规模以前是 0.4，见《测量与预算》"躯体规模按种族和时期"）×（1 + `yield_per_level`（0.1）×（等级 − 1））× √个头 × 时期倍率（`stage_yield`：0.6 / 1 / 1.5），按种类的 `material_ratio` 和词条倍率分到三类；总数四舍五入，幼年期至少 1 份、成长期和成年期至少 2 份（`min_materials`），按零头大小分（`CatchGenerator._split`）。新回合机制第 42 条：拆一条换回的饵不能比钓它花掉的多。每一条都拆得出东西：幼年的小鱼 1 份，成长期、成年期的至少够做一份饵，成年的大个、渡魂白鲟、带铁骨 / 血旺 / 磷腺的多几份 |
| 载荷 | `load_by_stage[时期]`：幼年 1 / 成长 2 / 成年 3（G2 起；原来按灵魂等级 1 / 2 / 4 / 8 / 16） |

词条：
- 普通（额外词条）：多肉（原名肥硕；饱腹 ×1.4，祭值 +10%）、枯瘦（饱腹 ×0.6，祭值 −20%）、铁骨（矿壳 ×1.7，祭值 +8%）、血旺（血肉 ×1.7，祭值 +12%）、磷腺（幽光 ×2，祭值 +8%）、魂蕴（原名魂浓；灵魂强度 +20，祭值 +25%，灵魂强度高了祭值再多一截）。
- 特殊：「变色」（3%，祭值 +40%）插图转到另一个色相、颜色浓一些；「变异」（1%，祭值翻倍）插图一鼓一鼓地扭、皮下爬着一跳一跳的暗红纹（`shaders/creature_display.gdshader` 的 `hue_shift`、`mutation`；船舱、供奉里的小图乘一个对应的颜色，`Gothic.catch_tint`）；带「变异」的躯体规模写畸变。自动垂钓碰到带特殊词条的停下来交给你。
- 词条只改用途上的数值，不改捕猎难度。

## 饱腹（核心调整 G3，设计对照文档 8.3）
契约者身上的饱腹（`Contractor.hunger`，0–`hunger_max` 100），挂在体力下面（张力计下面一根细管）。数值在 `BalanceConfig` 的"饱腹"一组：
- **签约时是满的**，跟着契约过夜；换人时新的契约者也是满的。
- **跟着捕猎行动往下掉**（`Contractor.spend_hunger`；新回合机制第 36 条）：每抛一竿 `hunger_per_cast`（4），搏斗里每耗 1 点体力再 `hunger_per_stamina`（0.05；`TensionModel.spent`，难打的一场多吃掉几口）。看渔获、契约书、制饵、黄昏时不掉。原来是跟着夜里的钟每秒掉 0.22（6 分钟一夜约 80），一夜没有钟以后改成这样。
- **生吞一条加回来**，到 100 为止。
- **饿了**（`hungry_at`：60、30）：60 以下体力上限 ×0.85，30 以下 ×0.65、搏斗里体力还掉得快 1.2 倍（`hungry_stamina`、`starving_drain`）。上钩时按那一刻的饱腹定这一场的体力（`TensionModel` 的 `stamina_limit`、`drain_mult`），歇着回体力也回不过这个上限。饿到下一档时日志里说一句，准备抛竿时提示"饿了：钓上来的生吞了能顶饿"。
- **吃撑了**：满了还能吃，饱腹装不下的那部分就白吃了。`Contractor.eat_gain(c)` 给出现在吃能加多少饱腹、有多少装不下，渔获展示、契约书、日志用的都是它。
  （2026-11-04 以前装不下的那部分对应的成长只算一半；生吞不长级以后只剩这一条。）
- **饱餐**（奖励卡，H2）马上加 40 饱腹。原来还管"下一夜吃撑了不打折"，生吞不长级以后没用了，2026-11-04 删了。

## 契约者（`scripts/core/contractor.gd`）
一位契约者的烙印、能力档、饱腹、船舱、材料。纯逻辑，界面、测试、以后的整局模拟器用同一套；`GameState.contractor` 是当前这位。
落水死了就换下一位（`GameState.next_contractor`）：
- 编号 +1，整个换掉。
- 饵料篓清空；新契约者带开局的材料和附加物，另送一份腥糜饵（《饵料系统》）。
- 只留名册（`GameState.roster`，名册界面在阶段 D 做）和图鉴（`GameState.catches`）。
- 换人时发 `contractor_changed`，界面重新连到新的契约者上。
- 船舱上限 20（`hold_capacity`，2026-11-04 你定的）：不分等级，以后用别的机制加（原来跟着灵魂等级 3 / 5 / 9，再早按船的等级 3 / 6）。
- **没有等级了**（2026-11-04 你说的；生物的等级不变）：生吞不长级，原来的灵魂等级、成长、升级（`soul_level_max`、`growth_to_level_up`、`growth_by_level`、`overfull_growth`）都删了。
  体力上限、收线、张力这些本事的梯度先留着，叫**能力档**（`Contractor.ability`，1–3）；新的机制接进来之前跟着夜数走：第 1、2 夜 1 档，第 3、4 夜 2 档，第 5 夜起 3 档（`ability_by_night`）。
  测试和模拟器要固定能力档的，设 `ability_override`。
- 和各级生物比谁强按强弱表（`fight_gaps`，见《钓鱼与搏斗》"强弱表"），按能力档查：1 档和 1 级的相当，2 档和 2、3 级的相当，3 档和 4 级的相当。

## 奖励卡改渔获的两张（H2，见《契约与昼夜》"供奉后的补给与奖励卡"）
- **进化**（`CatchGenerator.evolve`、`Contractor.evolve_catch`）：带着它，下一夜钓上来的第一条长一个时期，幼年的有三成直接长成年（卡的 `amount`）；
  成年的长不了，卡留给下一条。等级跟着时期走（`stage_levels`；只差一级的种类的成长期，还是按灵魂强度过没过门槛定）。
  躯体规模、灵魂强度按它在原来那个时期里的位置换过去：躯体规模换到新时期那一档、在档里的位置不变，灵魂强度挪过新时期的平均差（大个的还是大个，魂浓的还是魂浓），词条不变；
  能量按新旧两级的平均能量换（`energy_for(新) ÷ energy_for(旧)`），祭值、饱腹、材料、载荷都重算。例：幼年的磷灯婆（1 级，祭值一千四上下）长成成长期是 2 级、四千上下，载荷 1 → 2。
  展示时介绍前面写"进化：幼年期 → 成长期"。
- **永久恩赐改渔获的**（v0.23，见《契约与昼夜》"永久恩赐"）：
  - 剔骨：分解时多一份最多的那种材料，每夜两次，展示和契约书里的 +N 已经算上。
  - 残躯为饵：拆了一条以后，这一夜下一条留下的祭值 +20%，展示时介绍里写"残躯为饵：留下它，祭值 +20%"。
  - 异象收藏：船舱里带特殊词条的每过一夜 +25%。
  - 加的都记在 `CatchData.bonus`，算祭值时乘进去。
  - 进化改成永久的（每夜第一条，不跳级）。
  - 特殊词条的机会跟着冥海侵蚀和海况变（`special_chance_mult`）：第 7 夜 ×1.9，异化的夜再 ×3。
- **剖腹**（`Contractor.dismantle_yield`）：带着它的那一夜，每一次处理材料都翻倍。渔获展示的"处理材料"一栏、契约书里材料后面的 +N 写的都是翻倍以后的，展示里的字是幽绿的。
- 引深换的是咬钩的那一条（`CatchGenerator.generate_at_level`：比契约者的能力档高一级的各个"种类 × 时期"按稀有度、时期的比例、饵的倍率挑，不看水层），见《钓鱼与搏斗》。

## 三层水（2026-11-03，`scripts/core/water_layers.gd`）
浅滩、中层合成浅层，一共三层：浅层、深水、渊底（`GameDB.DEPTH_NAMES`）。每层水出几级的生物是定好的（`layer_levels`），生物的等级跟着时期走，
所以一层水里出什么种类、什么时期，是按等级挑出来的：这层水里的每一级分到它那一份，再按"种类 × 时期"的稀有度 × `stage_share` 分给这一级的各个。
挂万能饵时一层水里各级占的就是下表；做的饵只看种类（基础材料合不合、附加物的气味），在这上面再乘（《饵料系统》）。

| 水层 | 出几级的（你定的） | 定的比例 | 挂万能饵时咬钩的 | 每咬一口平均祭值 |
|---|---|---|---|---|
| 浅层 | 只出 1 级 | 1 级 100% | 灰鲦 54%（三个时期）、血齿冥鲳 34%（幼年、成长期 1 级）、磷灯婆 12%（幼年） | 1,250 |
| 深水 | 3 级 < 1 级 < 2 级 | 1 级 30%、2 级 50%、3 级 20% | 盲眼噬骸鳗 23%、血齿冥鲳 22%、灰鲦 16%、千目窥渊鲶 13%、磷灯婆 11%、溺者之手 11%、渡魂白鲟 3%（幼年） | 2,750 |
| 渊底 | 2 级极少、3 级最多、4 级略少、5 级再略少，没有 1 级 | 2 级 5%、3 级 35%、4 级 32%、5 级 28% | 渡魂白鲟 43%、千目窥渊鲶 21%、溺者之手 17%、盲眼噬骸鳗 13%、磷灯婆 4%、血齿冥鲳 1% | 8,900 |

具体的比例是我按你说的大小关系定的（2026-11-03 第二轮：深水 3 级 < 1 级 < 2 级；渊底 2 级极小、3 级稍高、4 级略小于 3 级、5 级略小于 4 级），
在 `data/balance.tres` 的"水层"一组里改。5 级的只有成年的渡魂白鲟，所以渊底有四成多是白鲟。

## 种类数据（`data/fish/*.tres`）
在原有的偏好、稀有度、水层、挣扎、耐力之外，新增：
- `icon`：插图（成长期）；`icon_juvenile`、`icon_adult`：幼年期、成年期的插图（`stage_icon(时期)` 取，没有的用成长期那张）
- 个体：`level_min` / `level_max`、`adult_body`（成年期的躯体规模是哪一档：0 小型、1 中型、2 大型、3 巨型、4 畸变；2026-11-04 代替原来的 `weight_min` / `weight_max` 公斤）
- 用途：`yield_base`、`material_ratio`（`{"flesh": …, "shell": …, "glow": …}`，自动归一）。原来的 `food_base`（饱食度）G3 删了：饱腹只看躯体规模
- 祭值：`tribute_base`（种类基础值）：灰鲦 300、血齿冥鲳 380、磷灯婆 420、盲眼噬骸鳗 270、溺者之手 240、千目窥渊鲶 300、渡魂白鲟 260。原来的种族加成（`tribute_bonus`，加在等级² 上）2026-11-03 去掉了，等级的那一截 2026-11-04 起在能量里（`energy_by_level`；原来是 `level_tribute`）
- 展示：`motion_style`（怎么动：鱼、鳗、灯笼、手、水母、鲀、蟹、扁的、螺、鲸，2026-11-05，见下面"插图的动态"）、`motion_amplitude`（身子的摆幅，占插图高度的比例）、`motion_speed`（每秒摆几下）、`motion_wavelength`（波长，按身长算，越小身上同时出现的弯越多）。
  现在：灰鲦、血齿冥鲳、千目窥渊鲶、渡魂白鲟是鱼，磷灯婆是灯笼，盲眼噬骸鳗是鳗，溺者之手是手。

- **可以换成画好的素材**（有就用，没有照现在这样画）：格子的框 `assets/ui/codex_tile.png`、选中的框 `codex_tile_lit.png`（都按格子四周外扩 6 像素画）、立绘后面的底 `codex_portrait.png`；每种的小图 `assets/creatures/icons/<id>.png`。要求见《冥海契约_阶段V_种族名册与美术需求》第 6 节。
- **数从哪来**（`scripts/core/codex.gd`，`Codex`）：只读 `data/fish/*.tres` 和数值总表，什么都不存，改了数图鉴跟着变。
  - 钓上来是哪个时期几级：`WaterLayers.entries`（和 `CatchGenerator.generate` 挑的一样）。
  - 常见的一条（`typical`）：躯体规模在这个时期那一档的中间（`CatchGenerator.typical_body`）、这一级这一时期的平均灵魂强度（成长期分两级的，取门槛那一边的平均）、这一级的平均能量、没有词条。祭值对能量、灵魂强度各是一次式（两样各掷各的），这一条的祭值就是平均数；带词条的平均多 4–5%。

## 文字按钮的统一样式（`scripts/ui/gothic/key_prompt.gd`）
全界面的文字按钮都是 `KeyPrompt`："[键] 文字"，键名古铜色、文字骨白，黑描边。右下角的按键提示、渔获展示的四个去向、船舱里的按钮都是它：能点的悬停时提亮、下面浮出一道细线，按下时往下沉一个像素；不可用时整体发灰；没有快捷键的只写文字。以后的新界面也用它，不要另起样式。

## 试玩日志（`scripts/autoload/play_log.gd`）
每次启动写一个 `user://playlogs/年月日_时分秒.jsonl`（Windows 上是 `%APPDATA%\Godot\app_userdata\冥海契约\playlogs\`），一行一个事件。只有界面层写，自动测试不留文件。

| 事件 | 记什么 |
|---|---|
| `craft` | 制饵：做了什么，身上还剩什么材料和附加物 |
| `cast` | 饵（或空钩）的基础组合和附加物、水层、咬钩的是什么 |
| `bite` | 真咬钩（这时才扣饵）：是什么、等级差、哪种饵 |
| `miss` | 收竿太早 / 没来得及提竿 / 空钩，以及等级差 |
| `hook` | 提竿：对手、等级、等级差、饱腹；自动提竿的带 `auto` 和钓上来的机会 |
| `fight` | 结局（`caught` 钓上 / `slipped` 脱钩 / `cut` 剪线 / `gamble_won` 硬撑钓上 / `fell` 落水）、用时、等级差、体力最低到多少、剩几枚烙印；自动的带 `auto`、机会、耗了多少体力 |
| `exhausted` | 体力耗尽：硬撑的机会、剩几枚烙印 |
| `auto` | 自动垂钓开、停（`why`：你关掉了 / 饵用完了 / 船舱放不下了）；停在咬钩那一刻交给你的带 `takeover`、是什么、等级差 |
| `gamble` | 硬撑：机会、赢没赢 |
| `death` | 死因（`fall` 落水 / `offering` 供奉不够被吞噬）、第几位契约者、第几夜 |
| 契约周期 | `sign`、`night`、`dusk`、`offering`、`repaid`、`salvage`、`item`，见《契约与昼夜》 |
| `catch` | 个体的全部数值 |
| `decide` | 去处（`keep` / `eat` / `dismantle`；自动留进船舱的 `from` 是 `auto`），以及之后的能力档、载荷、饱腹、材料 |
| `hungry` | 饿到下一档（1 饿了、2 饿得发慌）：那时的饱腹、这一夜还剩几秒 |
