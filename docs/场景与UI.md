# 夜海场景与哥特风 HUD

美术参考（`docs/reference/`）：
- `ui_style.webp`：HUD 风格（骨架道具栏、羊皮卷格子、黑铁张力计、罗盘）
- `mood_fog_teal.webp`：氛围（静谧、青蓝暗调、灰白雾气留白、雾中巨物、零星暖光）
- `boat_source.webp`：船头原画

## 画面分层（`scripts/ui/fishing_view.gd`）
```
WaterView（scripts/ui/water_view.gd）
  _cloud_viewports + sky_clouds.gdshader  体积云，两张 1/3 分辨率的离屏图轮流画、逐帧累积（见"大气"）
  sea_scene.gdshader   夜空和月亮（盖上离屏图里的云）、礁石、雾、海面、低雾、礁石上的灯
  SkyBirds（夜里偶尔飞过的大鸟：sky_birds.gdshader 画的剪影，在云和雾里若隐若现；天之上、祂之下）
  GodPresence（黄昏时的祂：原画 + god_presence.gdshader、黑雾 god_fog.gdshader、眼睛；在天和海之上、浮漂和船之下）
  浮漂与水纹（DrawLayer）、鱼线（DrawLayer，被船身挡住）
  船：3D 木船（Boat3D，透明 SubViewport 渲染成一层，boat_toon.gdshader）；关掉 boat_3d 就是原来的船头贴图 + boat.gdshader
  Lantern（scripts/ui/lantern.gd）：灯架 + 单摆挂灯 + 加色光晕
  水花粒子（左舷 / 船头 / 右舷）
FirstPersonArms（3D 手和鱼竿，透明 SubViewport）
RainLayer（下雨时的雨丝，scripts/ui/rain_layer.gd + rain.gdshader；在手和鱼竿之上、后期之下）
grade.gdshader（后期：泛光、月光光柱、灯在雾里的光晕、前景淡雾、青蓝调色、暗角、颗粒）
HUD（scripts/ui/gothic/）
```
只有钓鱼这一个画面。`E` 打开制饵界面（`BaitBench`），`Tab` 打开契约书，都是盖在压暗的海面上的整屏界面。开局先签约（`SigningScreen`）；死了、契约已偿以后先出结算清单（`SettlementScreen`），再签下一位；一夜没有钟，按 `F` 先确认（`SummonPrompt`）再唤祂；夜里到点进黄昏：天转暗红，祂从雾里浮出来，然后供奉（见《契约与昼夜》）。

**海面、礁石、天空都不是 3D 模型**：整个场景画在一张全屏 2D 面片上，着色器给每个像素从虚拟相机射一条光线，
在数学上和海面高度场求交、和礁石的有向距离场（SDF）求交、在云层里步进，再算光照和雾。
所以看起来是 3D 的（浪会互相遮挡、礁石有透视和体积），但没有网格，也不进 Godot 的 3D 场景。
手和鱼竿（`FirstPersonArms`）、船（`Boat3D`）是真 3D，各自渲染到透明 SubViewport 叠在上面。`sea_common.gdshaderinc` 是海面和云两个着色器共用的相机参数、噪声和云的形状。

## 相机与船的运动
- 船的运动**不是另编的动画**：`WaterView` 用和着色器同一组涌浪参数（`SWELLS`），在船头、船尾、左右舷取样海面高度，算出起伏、俯仰、横摇，再用弹簧加上船体惯性（`MOTION_SPRING`）。船是真的骑在画面里的浪上。
- 人坐在船上会本能地稳住视线：横摇和俯仰里 `VIEW_STABILIZATION`（0.55）这部分由视线承担（整片海面在屏幕上倾斜、地平线上下移动），剩下的由**船身自己晃出来**（贴图绕屏幕下沿正中转、船头抬起时整条船往上走；3D 木船见下）。起伏（上下）全部由视线承担。
- **船身贴图的底边永远不会露出来**：每帧量出旋转、上抬之后底边在屏幕左右两端的高度，离屏幕下沿不足 `BOTTOM_MARGIN` 就整体往下压。`tests/test_boat_motion.tscn` 会模拟几分钟海浪逐帧检查：正常海况下最大倾斜约 1.5°、最大上下约 57 像素，底边最近也在屏幕下沿以下 30 像素，完全用不到下压；三倍浪高或把船调小时才会触发下压，底边同样不露。
- 涌浪参数只在 `WaterView.SWELLS` 里定义一次，每帧写入着色器的 `swells[]`。改波浪只改这里。
- 船头往下扎得够快（`SLAM_RATE`）时，船舷和船头溅水花。
- 鲸油灯：灯架跟着船身一起晃，灯像单摆一样朝真正的"下"摆过去、比船慢一拍；火苗的闪烁（`lamp_flicker`）同时驱动海面、船身、手、后期光晕。
- 船的位置和大小：`FishingView` 的导出参数 `boat_screen_top`（0.66）、`boat_width_ratio`（1.18），检查器里可调，编辑器里有预览。地平线 `WaterView.HORIZON` = 0.12（屏幕高度的 62% 处），船头刚好在地平线下方。
- 鱼线遮挡（入水点贴着船舷外侧走）在船身贴图的本地坐标里算，船身晃动时依然准确；只横向挪动入水点，纵向位置保持投影结果。
- **祂发怒时的震动**（`WaterView.quake`）：给地平线和横摇加一阵低沉的晃（5 Hz 上下）叠一点碎抖（12 Hz 上下），每秒退到 e^-2.4。震的是视线，所以海、天、祂、船、浮漂、雨丝一起抖，四边不露空；有多狠由 `FishingView.ANGER_QUAKE` 按发怒的程度给。

## 转头（只有 3D 木船能转）
- **怎么转**：钓鱼时鼠标藏起来、锁在窗口里（`FishingView.capture_mouse`），移动鼠标就是转头（`look_sensitivity`）；按住 A / D 也能慢慢转。左右加起来 `FishingView.look_range`（60°），检查器里可调。
  - 按住 Alt 放出鼠标（点骨架栏换饵、换水层，点道具），松开又藏起来。打开契约书、制饵、看渔获、供奉，以及签约、死的时候，鼠标也放出来；窗口没有焦点时不锁。
  - 视线平滑地追上目标（`LOOK_RESPONSE`）。
  - 黄昏祂出来、签约、死的时候拉回正前方，转不动。
  - 自动演示（`tests/showcase.gd`）和对比截图（`tests/boat_compare.gd`）把 `capture_mouse` 关掉，免得抢走桌面上的鼠标。
- **怎么做的**：视线绕竖直轴转 `yaw`（> 0 朝右看）。
  - 海面、礁石、月亮、雾按世界算：着色器里先按没转头算出视线方向，再用 `yaw_dir` 转到世界里（`sea_common.gdshaderinc`）。
  - 云图跟着视线转，上一帧的云图按方向对回来再累积（`history_yaw`），所以云的开销不变。
  - `WaterView._project` / `_unproject` 先转到视线坐标再投影：浮漂、鱼线、灯、月亮在屏幕上都对得上。3D 木船的相机跟着转，船不动。
  - 手和鱼竿跟着人转，在画面上不动。
- **抛竿**：朝哪看就往哪抛（`WaterView.cast_yaw`）。罗盘按视线指：浮漂、鱼在哪个方向；空竿时指着船头。
- 船头贴图（`FishingView.boat_3d` 关掉时）是一张固定的画，不能转。

## 3D 木船（`scripts/ui/boat_3d.gd`）
- **模型**：`assets/models/木船2.glb`，两块网格各一套贴图：装饰件（横梁、铁件的图集）、船板（横着的木板，在 UV 里平铺）。
  - 贴图：`assets/textures/boat3d_{trim,planks}_albedo.png`（原件的颜色，512）、`_normal.png`、`_roughness.png`（1024）。
  - 原件在 `art_src/木船2.glb`，只有颜色贴图，没有法线和粗糙度。这个文件夹 Godot 不导入（`.gdignore`）、git 不收（`.gitignore`）。
  - `python tools/convert_boat.py` 从原件转出来：
    - 网格：原件是厘米、套着 0.01 的缩放，转成米；去掉原件摆在场景里的位移。
    - 法线：照着颜色画。亮度当高度，板缝、木纹里深色的地方凹下去；先去掉大块的深浅，再叠细木纹和板缝两层；铁件（偏灰蓝、不饱和）压平一些。贴图平铺，求导、模糊都首尾相接。
    - 粗糙度：木头整体很粗糙（0.8 上下），板缝和脏的地方更粗糙，磨亮的浅色木面稍微光一点；铁件光滑一些（0.4~0.55）。
    - 各项强度在脚本开头改，改完重新跑一遍。
  - 模型坐标：船头朝 +Z（船头柱顶 z = 4.87、高 1.72），船尾 −4.09，龙骨 y = −0.2，船舷约 1.07，宽 3.07 米。
- **相机和海面是同一个针孔投影**：
  - 3D 那层只渲染"船平稳、地平线在正中"的画面：竖直视角按 `FOCAL` 换算，四周多渲染一圈 `BOAT_3D_MARGIN`。
  - 地平线下移、视线承担的俯仰和横摇，由 `WaterView` 把整层在 2D 里平移、绕屏幕中心转，和 `_project` 一模一样。所以船和海面、浮漂、鱼线对得上。
  - 船身自己晃的那部分（1 − `VIEW_STABILIZATION`）在 3D 里绕眼睛正下方水线上的一点转，船头的摆动有真的透视。升沉不用管：人和船一起起落。
- **人坐在哪**：`FishingView.boat_seat_z`（1.47；船头柱顶 +4.87、船尾 −4.09），越大越靠前、船头越大。
  - 眼睛在模型里高 `Boat3D.EYE_Y`（1.62 米，比船舷高半米多），离水面 `CAM_HEIGHT`（1.55 米）。
  - 这样船头柱顶在前方 3.4 米、刚好高出地平线一点，和原来的船头贴图差不多。
- **着色**（`shaders/boat_toon.gdshader`）：和手同一个底子（交界线抖动、内轮廓墨线、纸张噪声），质感往参照图（风化的旧木船：哑光、木纹和板缝清楚）靠。
  - 颜色就是原件的颜色贴图，只乘一个 `albedo_tint` 整体调色。
  - 明暗用法线贴图上的朝向（`normal_strength`），交界线比手软（`shade_softness`）；凹下去的缝压暗（`relief_cavity`）；船底比船舷暗（`ao_bottom`：模型没烘环境光遮蔽，按高度近似）。
  - 粗糙度：旧木头大多是哑光，只有很宽、很淡的高光；铁件光一些（`spec_strength`），月光和船头灯各一份。
  - 月夜环境光、雾色跟着 `DUSK_BOAT` 一起在黄昏转红。船头灯的暖光平滑衰减、不分档。
  - 这些都是着色器里 uniform 的默认值，要调直接改 `boat_toon.gdshader`。
- **描线**（`shaders/boat_outline.gdshader`）：船在相机前放一块铺满画面的面片，按深度描两种线，都带和手一样的粗细抖动。
  - 外轮廓（`outline_px`，3.4 像素，和手一样）：一个像素周围一圈里前后深度差得多（`depth_jump`），就描黑。船对着海、横梁对着后面的船板都会描上。
  - 结构线（`crease_px`，2.6 像素，比外轮廓细一点、分得出主次）：两边是连着的面，但朝向差得多（夹角超过 `crease_angle` 35°），比如船舷方木的顶面和内侧面（看得出船舷的厚度）、船头甲板的屋脊和边、船头柱上的铁箍、横梁的棱。面的朝向从深度重建，所以只描模型上真的折角；船板之间的小转折、贴图里的木纹板缝都不描。几乎侧对着镜头的面不算（`grazing_limit`），不然会描出虚线。
  - 手用的是反转外壳描边；船的船舷、横梁是有厚度的方木，反转外壳在轮廓上大多被正面挡住，横梁的角上又会冒出一块块的，所以船改成看深度。
- **灯和水花**：鲸油灯挂在船头柱顶（网格的最高点），灯架跟着船头柱在屏幕上的朝向转，大小按远近（`LANTERN_SCALE_3D`）。水花从两舷船舷上沿（人前方 2 米处）和船头喷出。
- **鱼线遮挡**：开局从网格量出两舷船舷上沿（每 12 厘米一段），每帧投影到屏幕。入水点落在两条线之间时，沿船舷外侧拉近，和贴图版同一个规则。鱼线照样画在船这一层下面。
- **开关**：`FishingView.boat_3d`（默认开）。关掉就是原来的船头贴图，两套都在、互不影响。
- **自检**：`tests/test_boat_motion.tscn` 加了 3D 木船。
  - 正常海况和三倍浪高下，屏幕下面两个角始终在渲染出来的画面里。
  - 入水点从远到近、从左到右的 105 个位置，都不会落进船里。
- **对比截图**：`tests/boat_compare.tscn`（要出画面跑）。船停着、浮漂在远处、收线、黄昏四种状态，贴图船和 3D 木船各截一张；加 `raw` 只显示颜色贴图。

## 航行
- 船一直往前漂：空竿时 `SAIL_SPEED`（2 米/秒），下了钩就停桨、只随水漂（`DRIFT_SPEED`，0.6 米/秒），几秒内缓过去。不想减速就把两个设成一样。
- `WaterView._travel` 是已经漂出去的距离。着色器里 **世界坐标 = 相机坐标 + (0, 0, travel)**：海浪、泡沫、低雾、雾团、云都按世界坐标画，所以会从船边往后流；船的起伏、浮漂的高度也按同样的世界坐标取样海面。
- 迎着浪走，船晃得比停着时勤一点；`tests/test_boat_motion.tscn` 模拟时也带着航行。

## 礁石（`WaterView` 的礁石部分 + `sea_scene.gdshader` 的有向距离场）
- **摆放**：航路每 `ROCK_CELL`（90 米）一段，每段按段号（和 `ROUTE_SEED`）确定性地决定有没有礁石（`ROCK_CHANCE` 72%）、是哪一种、在左还是右、多大多高、有没有灯。同一段无论什么时候经过都长一个样，不存档也不会变。
- **四种**：
  | 类型 | 形状 | 位置 |
  |---|---|---|
  | 海蚀柱（42%） | 一根主柱 + 两根矮一些的副柱长在一起，截面椭圆、往上收、轴线歪斜；高低不齐的层理浅槽 | 航路两侧 |
  | 海蚀拱（12%） | 两根柱子 + 顶面起伏、中间微塌的石梁，中间掏出拱洞 | 多在一侧；约三分之一正好横跨航路，船从拱洞底下穿过去 |
  | 崖壁（18%） | 顺着航路的一长段石墙，两头塌下去，正面竖向柱状节理，脚下碎石坡，越往上越往后收 | 航路两侧 |
  | 低礁（28%） | 几块半沉在水里的圆石，浪在上面碎成白花 | 离航路近 |
- **由远及近**：每帧挑离船最近的 `MAX_ROCKS`（8）处写给着色器。礁石在 `ROCK_AHEAD`（720 米）开始生成，着色器在 480~700 米之间把它从雾里淡出来（淡到它身后本来的天空和雾），所以不会突然冒出来；退到身后就不再画。贴着海面的雾很浓，高耸的礁石顶却能从雾里探出来，远看是剪影，近了才看清岩面。
- **着色**：玄武岩的深青灰底色、层理明暗、雨水和鸟粪冲出的竖条、朝上台阶的盐霜；吃水线往上几米是湿的（更暗、反光）；月光多是侧逆光，明暗交界收得软；朝上的面接夜空的暗青，侧面和下半截接周围被照亮的雾；近处再加一层细碎的岩面起伏。礁石脚下有碎浪，水里有倒影（倒影用粗一点的步进）。
- **灯**：约三成的海蚀柱和崖壁脚下点着一盏灯：在雾里散成一团暖晕（比礁石本身更早透出雾来），照亮旁边的岩面，在浪面上拖出一道碎金。
- **噪声贴图**：礁石的步进里要取成千上万次噪声，所以用 `WaterView` 开场用 FastNoiseLite 生成的可平铺噪声贴图（3D 64³、2D 256²）代替现算，速度快一倍。海面的噪声仍是现算的，没有动。

## 海面（`shaders/sea_scene.gdshader`）
几何分三层：
| 层 | 做法 | 作用 |
|---|---|---|
| 涌浪 | 5 组方向波，深水色散 ω = √(g·k)，二阶斯托克斯尖顶（`stokes`），解析法线 | 大起伏，船跟着它动 |
| 风浪 | 山脊噪声，每个八度旋转、两层不同方向平流 | 不重复的小浪，会"长"会"消" |
| 细纹 | 只扰动法线，28 米外淡出 | 近处的细碎反光 |

海面用**高度场光线求交**，浪会互相遮挡，看得出真实起伏。几乎平视地平线、600 米内碰不到海面的光线直接当作远处海面（以前这里会除以零，地平线上冒零星黑点）。
- **先找第一个浪头，再收敛**（2026-11-05 改，`trace_sea`）：沿视线往前走（最多 `SEA_MARCH` 36 步），找到第一次从水面以上到水面以下的那一小段，
  再在这一小段里用割线法收敛 `SEA_REFINE` 6 次。步长：离水面 h 米走 2h 米（海面最陡 0.5 上下，碰不上浪），离得越远步子越大（0.5 + 距离 × 0.04；100 米外九成多在雾里）。
- 原来直接在上下包围平面之间（视线从浪顶以上到浪底以下的整段）收敛 9 次：快平视的视线这一段有几百米、好几个浪头，会收到随便哪一个上，
  相邻像素落在不同的浪上，中远处的海面就是一道道条带。**往左看最明显**：几道长涌浪都从左前方来（`WaterView.SWELLS`），往左看时视线几乎迎着浪走（夹角十来度），
  一条视线穿过的浪头最多；往右看夹角五十来度，少得多。
- 测法：用一个每条视线走 400 步的参考求交逐像素比，落错浪头的像素往左看 13,875 → 2,949、往右看 4,908 → 2,918，剩下的都在地平线上那一线（全在雾里）。
  GPU 每帧多 0.15 毫秒左右（RTX 5070，1280×720：0.86–1.05 → 1.01–1.20 毫秒）。
- 截图：`tests/sky_capture.tscn -- only=look`：往左、正前、往右各一张，没雨、下雨各一组，日志里印每个方向的 GPU 时间。

着色分层：水体吸收色（`water_deep`）→ 浪尖透光（`water_scatter`，迎着月光的浪尖泛青）→ 菲涅尔反射（天空和云从同一张云图里按反射方向取，礁石的倒影另外步进）→ 月光路（光斑宽、碎闪少）→ 船头灯、礁石灯的高光 → 白浪（Worley 网格的蕾丝泡沫）+ 顺风拉长的泡沫纹 → 礁石脚下一涌一涌的碎浪 → 零星的青绿磷火。船身一圈的泡沫水纹已去掉。

## 大气
- **雾**（`fog_density` 0.0264/米、`fog_height` 8 米）：浓度随高度指数变稀，沿视线解析积分。贴着海面最浓（约 100 米外的海面完全化进雾里），往上越来越稀，所以高耸的礁石顶能探出雾来；并成团漂移。雾的颜色朝月亮的方向更亮，往高处看越来越暗。`WaterView.FOG_DENSITY` / `FOG_HEIGHT` 和它一致（浮漂、鱼线用同样的雾）。
- **雾堤**：海平线上的雾层厚度随方位起伏，上缘参差不齐，海天交界处没有清楚的线。
- **低雾**：沿视线在 7~40 米取样，贴着水面流动。
- **体积云**（`sky_clouds.gdshader`）：云层在 450~1300 米高，沿视线步进 48 次；每一步朝月亮再取两次样算自阴影；前向散射（迎着月亮的薄云边发亮）+ 粉末效应（云团边亮芯暗）+ 一点多次散射；云顶接夜空的暗青，云底只接海面和雾反上来的一点光。云底一团团往下鼓（越厚的云垂得越低）。月亮附近的云薄成一层纱（美术上的取舍），月亮多半能透出来、四周云边被照亮。
- **云图和逐帧累积**（体积云通行的做法，Godot 自己的体积雾、各家引擎的体积云都靠它去噪）：
  - 云单独画在离屏图上，分辨率是屏幕真实像素的 1/3（屏幕宽度按最多 640 算，1080p 下约 665×273）。云图按**船平稳时的视角**铺开（`WaterView.CLOUD_RECT`：比屏幕左右各宽 2%、往上多 14%，下沿正好是地平线），不跟着船晃，每个像素永远对着天上同一个方向；海面着色器按方向从里面取（`dir_to_cloud_uv`），倒影也一样。
  - 每帧换一个步进起点（交错梯度噪声 + 黄金分割轮换）和像素内的取样位置（R2 序列），再和上一帧按 `CLOUD_HISTORY`（0.92）混合，相当于把最近十几帧的样本平均起来。步进只有 48 次，单帧看是有颗粒的，但颗粒每帧不同，平均掉就干净了；云图不跟船晃，所以不用重投影，也不会拖影。以前的颗粒每帧随机换、云图又跟着船晃，云边就一直在闪。
  - 两张图乒乓：这一帧画一张、读另一张（上一帧）。踩过的坑：用 `hint_screen_texture` 读自己的上一帧不行，那份拷贝的 alpha 被定成 1，透过率丢了，云变亮；开 `use_hdr_2d` 存浮点也不行，2D 改成按线性色彩算，`source_color` 颜色被换算，云整体变暗。所以云图是 8 位的，写入前加 ±半个台阶的抖动（随机舍入），否则每帧只挪 8% 的累积会卡在 8 位台阶上。
  - 改了窗口大小、或者船一帧里瞬移超过 20 米（调试、读档）就从头累积，前十来帧按平均数快速收拢。
  - 覆盖范围按正常海况算（地平线最多偏 0.093 个屏幕高、横摇 0.028 弧度）；浪大到三倍时屏幕角落可能超出云图，取的是边上的云，不会出错。
- **月亮**：`WaterView.MOON_POS`（屏幕坐标），盘面有深浅的月海、边缘略暗，四周一圈光晕；手臂的月光方向 `FirstPersonArms.MOON_LIGHT_DIR` 和它对应。
- 颜色参数：`sky_top`、`fog_dark` / `fog_light`（背向 / 朝向月亮的雾）、`moon_color`、`water_deep`、`water_scatter`、`foam_color`、`rock_dark` / `rock_light`、`lamp_color`；云的 `cloud_coverage`、`cloud_base`、`cloud_top`、`moon_strength`。

## 下雨（`WaterView.rain` 0~1；什么时候下、多大由 `Weather` 定，见《契约与昼夜》“天气”）
- **雨丝**（`scripts/ui/rain_layer.gd` + `shaders/rain.gdshader`）：叠在手和鱼竿之上、后期之下，雨也过一遍泛光和调色。四层远近不同的雨丝斜斜落下（远的细、密、淡、慢，近的粗、稀、快、亮），一阵一阵的；雨落在世界里，转头、船晃时整片跟着视线走；船头灯旁边的雨丝被照成暖色。
- **天和雾**（`WaterView._apply_dusk` 里和黄昏的颜色一起算）：云更厚（`cloud_coverage` 0.5 → 0.72），天、月光、雾压暗（`RAIN_DIM`），海上的雾浓六成（`RAIN_FOG`，浮漂、鱼线也用这个雾），后期里云缝漏下的月光柱减弱。
- **水面**（`sea_scene.gdshader` 的 `rain_ripples`）：近处（40 米内）的水面按世界坐标切成两层格子，每格隔一会儿落一滴：一圈圈往外扩的涟漪改法线，刚落下的地方溅起一点白；月光路发暗，贴水的低雾更浓。
- **船淋湿**（`boat_toon.gdshader` 的 `wet`）：木头变深，表面一层水膜发亮（高光更集中、更亮）。
- 没有雨声：项目里还没有音频。

## 天上的大鸟（`scripts/ui/sky_birds.gd` + `shaders/sky_birds.gdshader`）
- 一夜最多飞过一回（什么时候由 `Weather` 定）。只看得见剪影，看得出翅膀一下一下地扇：又大又远，所以扇得慢，扇几下滑一阵。
- 每回都不一样（`launch` 时随机）：一只孤零零的巨鸟（翼展占屏幕高 0.17~0.27，扇一下 2.8~3.8 秒，飞得低、贴着雾）、三两只、或者一小队四到六只排成人字；翅膀的长短宽窄、翅尖下垂、脖子尾巴、扇几下滑多久、从哪边飞到哪边、飞多高、隔着多少雾都随机。
- 画法：每只按距离场画（身子顺着飞的方向，两只翅膀各分内外两节，扇翅时外节慢半拍跟上），边缘是软的；飞进云里被云图遮住一些（`cloud_hide`），流动的雾一阵一阵吞掉它（`fog_eat`）；隔着的雾只让剪影变淡，不往雾色调亮（天有亮有暗，调亮了暗处会显出一只亮鸟）。
- 放在 `WaterView` 里天之上、祂之下；鸟在天上的方向用 `WaterView.sky_point`（方位角、仰角 → 屏幕）换成屏幕位置，跟着转头、地平线和横摇。
- 截图看效果：`tests/sky_capture.tscn`（出画面跑，截下雨、几种大鸟、祂发怒的四级）。

## 后期（`shaders/grade.gdshader`）
在手和船之上、HUD 之下：泛光（屏幕贴图的模糊 mip）、**月光光柱**（每个像素朝月亮取 32 个样，只收集月亮附近透光的地方：月亮被薄云半遮时，云缝里漏下一道道光，云、礁石、鱼竿挡住的地方就是光柱间的暗缝）、灯在雾里的光晕（`1/r` 衰减）、屏幕中段的淡雾、调色（轻微去饱和但保留暖色亮部、暗部推向青蓝、柔和 S 曲线）、暗角、胶片颗粒。

## 性能
RTX 5070、1920×1080、关垂直同步：开阔海面约 3.2 毫秒/帧（310 FPS），前方有大海蚀拱约 3.4~3.5 毫秒，船正从拱洞底下穿过（岩壁占半个屏幕）约 4.9 毫秒（205 FPS）。最贵的是礁石的步进，其次是海面；云图改成逐帧累积以后总帧时间没变（每帧只画一张云图），后期约 0.5 毫秒。中低端显卡如果吃力，先减 `MAX_ROCKS` 或着色器里礁石步进的次数（`trace_rocks` 的 72）。

## 美术贴图怎么来的
全部由 Python 脚本程序化烘焙（3 倍分辨率，Godot 里缩小显示、开了 mipmap）：
- `tools/bake_ui_art.py`：骨头、头骨、椎骨、坠子、羊皮卷、药瓶（+ 液体灰度图）、印章、图标、张力计、罗盘、分隔线、鲸油灯与灯架；`ledger` 组是灵魂火图标（`icon_soul`，现在给能力档用）。三类材料图标（`mat_flesh` / `mat_shell` / `mat_glow`）原来也在这一组，现在换成了 GPT 画的，不再烘焙。用法：`python tools/bake_ui_art.py [组名 ...] [--preview 目录]`，组名见脚本开头。
- `tools/art_kit.py`：通用工具（噪声、有向距离场、高度场打光、渐变映射、墨线描边、投影）。
- 做法：用 SDF 拼出轮廓 → 换算成高度 → 求法线打光 → 按光照做渐变映射得到手绘色阶 → 叠凹陷阴影、磨损、颗粒、污渍、裂纹 → 墨线描边（背光侧加粗）→ 投影。
- **生成的 PNG 可以直接在绘图软件里继续手绘修改**。改过的图不要再运行脚本覆盖（可以只烘焙别的组）。
- 新烘焙的 UI 贴图第一次导入后，要把对应 `.import` 里的 `mipmaps/generate` 改成 `true`（现有的都已改好）。
- 这些是 GPT 画的，不是脚本烘焙的：
  - 道具图标（续魂丝、镇魂钉、窥渊之眼）、万能饵、唤祂（`assets/icons/`，来自 GPT 素材文件夹里的《v0.14_道具奖励与召唤素材》，512 缩到 256，按预乘透明度缩）。奖励卡面和六张卡的图标也在那个文件夹里，H2 做卡的时候接。
  - 生物插图（`assets/creatures/`，见《渔获与船舱》）。
  - 烙印符号（`assets/ui/soul_brand.png`）。
